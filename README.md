# Student Mental Health Analysis using R

## Project Overview
This project analyzes student mental health using Exploratory Data Analysis (EDA) and a Decision Tree Machine Learning model in R.

## Objectives
- Analyze student mental health data.
- Identify factors affecting depression.
- Visualize relationships using graphs.
- Predict depression using a Decision Tree model.

## Tools and Technologies
- R Programming
- ggplot2
- dplyr
- caTools
- rpart
- rpart.plot

## Dataset
Student Mental Health Dataset (Kaggle)

## Workflow
1. Data Import
2. Data Exploration
3. Data Cleaning
4. Data Visualization
5. Data Preprocessing
6. Train-Test Split (70:30)
7. Decision Tree Model
8. Prediction
9. Confusion Matrix
10. Accuracy Evaluation

## Machine Learning Model
Decision Tree Classification

## Results
- Successfully trained a Decision Tree model.
- Predicted student depression.
- Evaluated using a confusion matrix and accuracy.
- Identified the most important factors influencing depression.
